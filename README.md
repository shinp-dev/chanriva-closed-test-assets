# CHANRIVA Closed Test Assets

This repository contains temporary files provided for participants in the **CHANRIVA closed test on Google Play**.

## Purpose

CHANRIVA uses the Edax Othello/Reversi engine for features such as:

- AI matches
- Post-game analysis

These features require the Edax evaluation file:

`eval.dat`

The official Edax distribution provides this file as part of a compressed release archive. To make setup easier for closed-test participants, this repository temporarily provides the **extracted, unmodified `eval.dat` file**.

## Official Edax Project

The official Edax project is available here:

https://github.com/abulmo/edax-reversi

For normal use, please obtain Edax and its evaluation data from the official project.

## Temporary Closed-Test Distribution

The `eval.dat` file in this repository is provided **only as a convenience for the CHANRIVA closed testing period**.

- The file has not been modified by Shinp Studio.
- The original file is distributed by the Edax project.
- This repository is not an official Edax distribution.
- This temporary copy is intended to be removed after the CHANRIVA closed test is completed.

## Using the File in CHANRIVA

1. Download `eval.dat` from this repository.
2. Open CHANRIVA.
3. Open the Edax / evaluation file settings.
4. Select the downloaded `eval.dat`.
5. After the file is successfully imported, AI play and analysis features will become available.

Online play and other basic CHANRIVA features can be used without `eval.dat`.
